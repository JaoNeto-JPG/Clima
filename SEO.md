# SEO do site Clima no Cerrado

Site: https://jaoneto-jpg.github.io/Clima/

## Palavras-chave escolhidas

1. clima no Cerrado
2. estação seca no Cerrado
3. tipos de nuvens

## Decisões tomadas

- **title e description:** cada página tem os seus. O title da página inicial usa as 3 palavras-chave (56 caracteres) e a description tem 145 caracteres. A página `sobre.html` tem title e description diferentes.
- **canonical:** cada página aponta para a própria URL no GitHub Pages.
- **Open Graph:** title, description, image (1200x630, URL absoluta), url, type e locale nas duas páginas.
- **Favicon:** `favicon.svg`, para evitar o erro 404 no console.
- **JSON-LD:** `Article` na página inicial e `FAQPage` em `sobre.html`, com perguntas que aparecem na própria página. Validado em validator.schema.org.
- **Imagens:** convertidas para WebP, com alt, width e height. As duas últimas usam `loading="lazy"`; a primeira não, porque aparece na primeira tela.
- **Links internos:** as duas páginas se ligam com textos descritivos, sem "clique aqui".
- **robots.txt e sitemap.xml:** na raiz do projeto, com as duas páginas listadas.
